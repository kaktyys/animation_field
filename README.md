Описание проекта

Программа представляет собой интерактивную графическую симуляцию трехмерного космического звездного поля. Реализовано движение звезд в 3D-пространстве с использованием формул перспективной проекции, где размер и скорость изменения координат объектов динамически зависят от расстояния до них.

Функциональные возможности


Основной функционал

•Эффект глубокого 3D-пространства за счет математической проекции координат
•Динамическое изменение размера и цвета звезд по мере их приближения к наблюдателю
•Автоматическая генерация новых звезд на дальнем плане при выходе текущих за границы экрана

Дополнительный функционал

•Регулировка скорости космического полета с помощью клавиатуры в реальном времени
•Интерактивное управление направлением движения (смещение центра проекции) вслед за курсором мыши

Требования к системе

• Python: 3.13
• Операционная система: Windows/macOS/Linux
• Библиотеки: Используется только стандартная библиотека tkinter (встроенная).

Установка и запуск

1. Клонирование репозитория

bash
git clone https://github.com
cd animation_field

2. Создание и активация виртуального окружения

Windows:
bash
python -m venv venv
venv\Scripts\activate

macOS/Linux:
bash
python3 -m venv venv
source venv/bin/activate

3. Установка зависимостей

bash
pip install -r requirements.txt

4. Запуск программы

bash
python main.py

5. Управление

• Стрелка Вверх — увеличить скорость полета звезд
• Стрелка Вниз — уменьшить скорость полета звезд
• Движение мыши — изменение направления полета (камера следует за курсором)

Структура проекта

markdown
animation_field/
├── venv/                        # Папка виртуального окружения
├── .gitignore                   # Настройки исключений Git
├── README.md                   # Документация проекта (этот файл)
├── requirements.txt            # Файл зависимостей проекта
├── main.py                     # Главная точка входа в программу
└── src/                        # Исходный код приложения
    ├── __init__.py
    ├── app.py                  # Графическое окно, интерфейс и главный цикл отрисовки
    └── models/
        ├── __init__.py
        └── animation_model.py  # Математическая модель поведения и координат звезд

Назначение основных модулей:
• main.py — запускает графический движок приложения.
• animation_model.py — хранит и пересчитывает 3D-координаты, скорость и цвета каждой отдельной звезды.
• app.py — отвечает за создание холста, обработку нажатий клавиш, физику перемещения мыши и перевод 3D-координат в 2D-точки экрана.
